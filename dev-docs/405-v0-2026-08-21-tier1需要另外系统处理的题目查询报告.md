## 2. 查询方法

### 2.1 核心逻辑

按每题**最后run的status**判断（不能用extraction_status，因为分布杂乱）。

### 2.2 关键JOIN和注意事项

| 要点 | 说明 |
|---|---|
| 关键JOIN | `problem_extraction_progress._key` = `devin_problem_runs.problem_id` |
| ⚠️ difficulty_tier | `devin_problem_runs.difficulty_tier`通常为null，必须先从`problem_extraction_progress`过滤tier=1 |
| ⚠️ extraction_status | 分布杂乱（queued/pending/completed/failed都有），不能用来判断题是否该入队 |
| batch_id过滤 | `batch_id='pipe-runner'`只查pipe系统的run |
| 排除运行中 | `status != 'running'`排除非终态 |
| 最后run | `SORT r.ended_at DESC LIMIT 1`取每题最后一条run |

### 2.3 AQL查询

```aql
FOR p IN problem_extraction_progress
  FILTER p.difficulty_tier == 1
  LET last_run = (
    FOR r IN devin_problem_runs
      FILTER r.problem_id == p._key
      FILTER r.batch_id == "pipe-runner"
      FILTER r.status != "running"
      SORT r.ended_at DESC
      LIMIT 1
      RETURN {status: r.status, exp_id: r.exp_id, ended_at: r.ended_at, runtime: r.runtime_seconds}
  )
  FILTER LENGTH(last_run) > 0
  FILTER last_run[0].status IN [
    "failed_token_limit", "ai_gave_up",
    "failed_stall", "failed_thinking_spin", "failed_no_proof",
    "invalid_tool_use"
  ]
  RETURN {
    key: p._key,
    source_dataset: p.source_dataset,
    last_status: last_run[0].status,
    last_exp_id: last_run[0].exp_id,
    last_ended_at: last_run[0].ended_at,
    last_runtime: last_run[0].runtime,
    answer: p.answer,
    has_solution: p.has_solution
  }
```

## 5. 另外一套系统的设计建议

基于查询结果，8,958题按失败原因可分为两大类：

### 5.1 token_limit题（8,225题，91.8%）

- **特征**：AI有思路但推理链被token预算截断
- **策略**：增大token预算（如从当前预算提升到更大），或分段推理（让AI先写大纲再逐段展开）
- **数据集分布**：polymath最多（4,171），其次是deepmath（1,553）和oda_math（1,231）
- **2026-08-22更新**：原9,336题中1,111题是误分类的连接错误，已扣除

### 5.2 ai_gave_up题（498题，4.9%）

- **特征**：AI主动输出"I CANNOT SOLVE THIS"
- **策略**：引导式推理（给提示）、提示词调整、或换更强模型
- **数据集分布**：formal_conjectures最多（437），这是Lean形式化猜想，AI可能不擅长形式化证明

### 5.3 边缘case（235题，2.6%）

- **特征**：failed_stall/failed_no_proof/failed_thinking_spin
- **策略**：可作为Profile数据保留，或针对性调试个别题
- **2026-08-22更新**：failed_no_proof的64题已重新入队重跑（无thinking数据），重跑后如果仍失败则归入此类
